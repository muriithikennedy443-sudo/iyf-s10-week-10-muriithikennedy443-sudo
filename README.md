## Project Description
A RESTful API built with Node.js and Express.js featuring posts management, user authentication middleware, error handling, and modular code organization. The project covers building APIs with in-memory data storage, middleware implementation, and environment variable configuration.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- dotenv
- Git & GitHub

## Features
- Full CRUD Posts API (GET, POST, PUT, DELETE, PATCH)
- Custom middleware (logger, auth, validation)
- Error handling middleware
- Modular project structure (routes, controllers, middleware)
- Environment variables with dotenv
- Query filtering, sorting and pagination
- Comments endpoint for posts
- User API with validation

## How to Run
1. Clone this repository
2. Navigate to any task folder
3. Install dependencies and start

## Lessons Learned
- How to build RESTful APIs with Express.js
- How middleware works in Express (logger, auth, error handling)
- How to organize code into routes, controllers, and middleware
- How to use environment variables securely with dotenv
- How to handle errors properly in Node.js applications
